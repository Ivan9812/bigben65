Редактирование в Figma

В Figma Desktop откройте новый файл. В меню Plugins → Development → Import plugin from manifest выберите figma-plugin/manifest.json. Запустите плагин BIG BEN Design Import, выберите устройства и нажмите «Создать экраны».

Плагин создаст настоящие Frame, Text, Rectangle и Vector: надписи и цвета можно менять. Сохраните файл через File → Save local copy, чтобы получить собственный .fig.

Можно также перетащить отдельные SVG из папки screens в Figma. Для редактируемого текста предпочтителен плагин.
